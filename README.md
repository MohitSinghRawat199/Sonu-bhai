# Suyash & Neha — Wedding Invitation

A responsive, Hindi-first wedding invitation built with React, Vite, Framer Motion, Lucide icons, and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL after the development server starts.

## Production build

```bash
npm run build
npm run preview
```

## Content notes

Wedding and family details are in `src/main.jsx` in the `content` object. The Maps button searches using the supplied venue address and does not claim a verified pin. The brief did not include the invitation PDF or any contact numbers, so no phone links are displayed. The devotional artwork is an original CSS motif inspired by a diya and Himalayan silhouettes, rather than a portrait presented as Maa बगी देवी. No audio file was supplied, so the intro states that audio is unavailable and does not imply that music is playing.
